# 90 秒展示講稿

**0–15 秒｜研究問題** 這個工具要問：兩檔股票的對數價差會不會回復？我比較預測不變、線性回復，以及 PySR 搜尋的公式。

**15–35 秒｜方法** 左側可選合成、TWSE 或本機 CSV，設定股票和日期切分。示範先用預先搜尋的合成公式，現場只跑評估。真實資料依時間切成訓練、驗證、測試；價差係數只用訓練資料估計，PySR 用訓練搜尋、驗證選公式，測試集不參與挑選。

**35–60 秒｜結果** 這組 TWSE 台積電和聯發科資料有 123 個共同交易日，測試 24 日。基準 MAE 是 0.008493；OU 是 0.008930；PySR 是 0.010204。兩個模型都沒有勝過基準。

**60–78 秒｜解讀** 所以這次結果沒有支持候選模型在測試期改善預測。測試很短、只有一組配對，也沒有調整股利與分割，不能推論長期穩定性。預測誤差也不是獲利。

**78–90 秒｜下一步** 下一步先固定更多配對與滾動測試日期，再用完全保留的新期間評估。這個工作台會輸出逐日預測和實驗紀錄，讓方程與結論都能追查。
