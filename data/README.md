## 下載來源資料

Streamlit 側欄選擇「TWSE 官方歷史資料（需網路）」，輸入兩個上市代碼與日期。程式以官方逐月端點順序查詢、檢查欄位並合併共同交易日；不補缺漏價格。官方端點如回傳非 JSON、限流或格式改變，程式會報錯，改用本機 CSV 或合成資料。

```text
https://www.twse.com.tw/rwd/zh/afterTrading/STOCK_DAY?date=YYYYMMDD&stockNo=2330&response=json
```
