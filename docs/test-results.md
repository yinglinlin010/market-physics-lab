## 自動測試

`uv run pytest`：**10 passed**。涵蓋下列檢查：

- 合成 AR(1) 價差回復係數估計。
- 擾動測試價格不影響訓練參數與驗證選出的公式。
- 三模型的測試日期一致、已存公式重載預測一致。
- 算式白名單、防止任意程式執行。
- 無效價格與不足切分資料回報錯誤。
- 僅依驗證誤差選公式。
- Streamlit 設定指紋改變時清除舊結果。
- TWSE 民國日期及價格欄位解析。
- 專案內官方 TWSE 樣本的共同日期、來源標記及資料指紋。
