# AI 開發過程摘要

## 選題與範圍

依使用者提供的期中規格，將研究問題收斂為：兩檔股票的對數價差，在固定時間切分下是否有回復傾向；PySR 搜尋的方程能否降低下一期價差變化的樣本外 MAE。第一版保留三模型、固定配對與一次時間測試，不加入交易回測、雲端 LLM 或多股票掃描。

## 採用的工具

- Python 3.12、Streamlit、pandas、NumPy、scikit-learn、Plotly：本機研究工具和資料處理。
- PySR 1.5.10 與其 Julia `SymbolicRegression.jl` 後端：候選方程搜尋。讀取 PySR 官方 repo 的 `skills/pysr/SKILL.md` 和官方文件，採用小算子集合、serial deterministic 搜尋、訓練集搜尋、驗證集選式、保存候選表與公式。
- 官方 TWSE 歷史端點和政府資料開放平台列示的開放資料授權：取得可追溯的台灣收盤價樣本。
- 官方 Impeccable skill：讀取當前 `SKILL.md`、Operate、新工作、Craft Floor、Init、Document 指引，執行 context 與 surface concept seed。頁面視覺依使用者指定的操作型研究工作台和具體欄位配置；不將不適用的海報或其他外觀指派套到研究工具。
- python-docx、python-pptx：產生可編輯的報告與簡報。

## 實際採用方式

1. 先用 seed=42 的合成回復價格測試資料邊界和估計，避免把模擬輸出說成股票結果。
2. 將官方來源的原始收盤價存成 CSV，附上授權、取得時間、價格調整定義和 SHA-256；同一份檔案與 manifest 供後續重算。
3. 對訓練期、驗證期、測試期採固定日期順序，purge 切分邊界的下一期標籤；沒有任何標準化步驟。
4. 搜尋公式和測試評估分離。公式來源是已執行的 PySR 程式、候選方程 CSV 和 JSON，不是 AI 手寫的替代公式。
5. Streamlit 預設合成資料以預先搜尋公式示範「公式預先搜尋、評估現場執行」。來源、設定改動會讓前次 session 結果失效。

## 除錯紀錄

- 首次 PySR 呼叫需要下載 Julia 和預編譯 Julia 相依套件。開發期完成初始化，並將預設合成公式、候選表、選式設定和測試預測保存，讓上台展示不依賴當場下載。
- PySR 第一次呼叫失敗，因 `temp_equation_file=True` 與 `output_directory` 同時使用。對照實際 PySR 1.5.10 traceback 後移除互斥選項，再以小型搜尋驗證候選表輸出。
- PySR 將 `variable_names` 寫入公式（`x`、`dx_lag1`、`vol20`），不是固定的 `x0`、`x1`、`x2`。安全算術重載器一開始只接受索引名稱；以搜尋輸出驗證後擴充白名單變數並重跑完整實驗。
- 官方 CSV 儲存的 ticker 欄可能被 pandas 解析為整數，與表單代碼字串不能相等。載入時明確將 ticker 正規化為字串，避免錯誤漏列。
- 一次測試斷言把 `bool` 傳入 `all()`，修正為直接比對日期陣列。另發現預先搜尋快取模式不會自動建立結果資料夾，加入輸出路徑初始化並重新做無 Julia 搜尋快取測試。
- 長區間 TWSE 查詢曾遇到空白回應。改以逐月逐股票低頻查詢、逐筆快取和明確回應錯誤訊息，並以 2026 年 5–10 月官方樣本完成實際匯入。

## 測試與觀察結果

自動測試 9 項全數通過，紀錄見 `docs/test-results.md`。合成資料上的模型差距極小：基準 MAE 0.009878、OU 0.009843、PySR 0.009947。這只證明程式可走完，不是股票結果。

官方 2330／2454 樣本為 123 個共同交易日，測試集只有 24 個預測日。無變化基準 MAE/RMSE 為 0.008493/0.010186；OU 為 0.008930/0.010853；PySR 為 0.010204/0.012943。測試集沒有用來挑公式或股票；兩模型都未勝過基準。這個短窗口不足以判定長期價差關係。

## 未完成或限制

- 只有一組真實配對，且測試只有 24 日；多配對、多期間與考慮時間相依的不確定性估計尚未做。
- 價格是原始 close，沒有做股利或分割調整；只反映實際指定的短期行情版本。
- 瀏覽器已實際執行合成資料主要路徑並看見指標、圖表、方程、結論及下載入口；手機尺寸和瀏覽器下載檔內容仍未驗證。Word 報告以 Microsoft Word 開啟檢查；Word 頁面 PNG 渲染工具缺少 `pdf2image`，系統也沒有 LibreOffice／Poppler。
- 真實行情下載需要 TWSE 服務可連線，預設離線展示則使用合成資料。
